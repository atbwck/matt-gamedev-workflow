# Game adaptation: triage

Preserve Matt's incoming-issue state machine, role labels, original brief and scope resources. Existing configured trackers and labels win. For game bug reports gather the build/version, platform, scene/map, save/seed, input/repro steps, expected/actual behavior and redacted engine logs/crash evidence. A user report is not a verified reproduction. Do not triage implementation tickets already produced from an agreed spec. Respect the user-only boundary and keep actual human answers distinct from inferred facts; no silent external messages, ticket publication or closure outside the requested scope.
