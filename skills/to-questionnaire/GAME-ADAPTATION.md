# Game adaptation: to-questionnaire

Preserve the interview about the recipient and the decision gap, then produce a named Markdown questionnaire. Game stakeholders may answer about art, audio, platform, accessibility or design intent. Do not silently send it, choose a recipient, or ask for credentials. Record incoming answers as actual human evidence before design decisions use them.
