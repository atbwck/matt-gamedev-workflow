# Game adaptation: pr

Retain the summary/evidence/merge-danger structure. For game changes include the actual scene/player/build/device evidence and asset/save/authority implications. Annotated captures can explain a behavior but do not replace test reports. Preserve the issue links and truthful not-run items. Drafting a PR body does not itself authorize creating or publishing a PR.
